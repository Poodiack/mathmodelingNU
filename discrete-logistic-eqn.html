Section 8.3 Discrete Logistic Equation

The table below gives the number of bacteria (in thousands) in a Petri dish, \(a_n\text{,}\) at the end of each hour \(n\text{.}\)

\begin{equation*} \begin{array}{c|cccccccccc}\hline\hline \pmb{n} \amp 0 \amp 1 \amp 2 \amp 3 \amp 4 \amp 5 \amp 6 \amp 7 \amp 8 \amp 9 \\ \pmb{a_n} \amp 10.3 \amp 17.2 \amp 27 \amp 45.3 \amp 80.2 \amp 125.3 \amp 176.2 \amp 255.6 \amp 330.8 \amp 390.4 \\\hline\hline \pmb{n} \amp 10 \amp 11 \amp 12 \amp 13 \amp 14 \amp 15 \amp 16 \amp 17 \amp 18 \amp 19 \\ \pmb{a_n} \amp 440 \amp 520.4 \amp 560.4 \amp 600.5 \amp 610.8 \amp 614.6 \amp 618.3 \amp 619.5 \amp 620 \amp 621 \\\hline\hline \end{array} \end{equation*}

This data is graphed below.

When modeling a dynamical system, it is often convenient to think about the way the variable(s) change(s) between time periods. We consider the change between time periods to be \(\Delta a_n = a_{n+1} - a_n\text{.}\) The values of this variable for the first seven values of \(n\) are given below.

\begin{equation*} \begin{array}{c|ccccccc}\hline\hline \pmb{n} \amp 0 \amp 1 \amp 2 \amp 3 \amp 4 \amp 5 \amp 6 \\\hline \pmb{a_n} \amp 10.3 \amp 17.2 \amp 27 \amp 45.3 \amp 80.2 \amp 125.3 \amp 176.2 \\ \pmb{\Delta a_n} \amp 6.9 \amp 9.8 \amp 18.3 \amp 34.9 \amp 45.1 \amp 50.9 \amp 79.4\\\hline\hline \end{array} \end{equation*}

Notice that as \(a_n\) increases, \(\Delta a_n\) also increases. This suggests that \(\Delta a_n\) is proportional to \(a_n\text{,}\) which leads to the equation

\begin{equation*} \Delta a_n = a_{n+1} - a_n = r\,a_n \end{equation*}

where \(r\) is some positive constant. An equation describing the difference in populations between time periods such as the one above is called a difference equation. Forming a difference equation is often the first step in modeling a discrete dynamical system. Solving this equation for \(a_{n+1}\) yields the model

\begin{equation*} a_{n+1} = (1+r)a_n. \end{equation*}

The parameter \(r\) can be interpreted here as a constant hourly growth rate. However, the graph of population versus hour shows that the population does not grow at a constant rate. Also note that this constant hourly growth rate would predict a population that grows without bound, which the data does not support either.

To refine the model, note that the graph shows that the rate of growth decreases as the population nears 621. This number is called the carrying capacity of the system. So instead of assuming a constant growth rate \(r\text{,}\) we assume a growth rate that approaches zero as the population nears 621. An equation implementing this assumption is

\begin{equation*} \Delta a_n = a_{n+1} - a_n = b(621-a_n)a_n \end{equation*}

where \(b\gt 0\) is a constant. Again, solving for \(a_{n+1}\) yields the model

\begin{equation*} a_{n+1} = a_n + b(621-a_n)a_n. \end{equation*}

This is called a discrete logistic equation.

Definition 8.3.1.

A discrete logistic equation (also called a logistic map or a constrained growth model) is an equation of the form

\begin{equation*} a_{n+1} = a_n + b(c-a_n)a_n \end{equation*}

where \(b\) and \(c\) are constants. This type of equation is often used to model population growth where \(a_n\) is the population at time \(n\text{.}\) The constant \(b\) is called the intrinsic growth rate and \(c\) is called the carrying capacity.

Example 8.3.2. Bacteria Growth.

To implement the model, we need to find the value of \(b\text{.}\) The equation says that \(a_{n+1} - a_n\) is proportional to \((621-a_n)a_n\text{.}\) So if the graph of \((a_{n+1}-a_n)\) versus \((621-a_n)a_n\) is approximately a straight line through the origin, then the assumption is reasonable and the slope of the line is the value of \(b\text{.}\)

First, we generate the list of the \(\Delta a_n\)'s.

Next we generate a list of the products \((621-a_n)a_n\) for all \(n\text{.}\)

We zip the two lists into a set of ordered pairs. We want the \((621-a_n)a_n\)'s to be the \(x\)-coordinates and the \(\Delta a_n\)'s to be the \(y\)-coordinates. (Think about why we need this order.)

We're checking for a proportionality relationship so we will to find the line through the origin that best fits these points using the find_fit command.

If we plot the line with the data, it appears to be a good fit.

Now we need to form the set of predicted populations, using our formula. We start the list with the first value in the data, and then add on all of the predicted points.

We form a set of points to plot using the zip command and then plot them using the points command.

Sensitivity to the Intrinsic Growth Rate.

In Section 8.2 we looked at how the long–term behavior of the savings account changes as the initial deposit changes. Now we look at how the behavior of our constrained population model changes as the value of \(b\) changes. We take a strictly graphical approach.

Notice that the behavior of the system changes quite dramatically as \(b\) changes. For small values of \(b\text{,}\) the behavior is very regular. But for larger values, it is quite chaotic. This illustrates that we must be careful about using a model of this form if we are unsure of the value of \(b\text{.}\) The value of \(b\) dramatically affects the behavior of the system. If we use a wrong value of \(b\text{,}\) our analysis of the system could be very inaccurate.

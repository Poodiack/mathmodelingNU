To implement the model, we need to find the value of \(b\text{.}\) The equation says that \(a_{n+1} - a_n\) is proportional to \((621-a_n)a_n\text{.}\) So if the graph of \((a_{n+1}-a_n)\) versus \((621-a_n)a_n\) is approximately a straight line through the origin, then the assumption is reasonable and the slope of the line is the value of \(b\text{.}\)

First, we generate the list of the \(\Delta a_n\)'s.

Next we generate a list of the products \((621-a_n)a_n\) for all \(n\text{.}\)

We zip the two lists into a set of ordered pairs. We want the \((621-a_n)a_n\)'s to be the \(x\)-coordinates and the \(\Delta a_n\)'s to be the \(y\)-coordinates. (Think about why we need this order.)

We're checking for a proportionality relationship so we will to find the line through the origin that best fits these points using the find_fit command.

If we plot the line with the data, it appears to be a good fit.

Now we need to form the set of predicted populations, using our formula. We start the list with the first value in the data, and then add on all of the predicted points.

We form a set of points to plot using the zip command and then plot them using the points command.

Sensitivity to the Intrinsic Growth Rate.

In Section 8.2 we looked at how the long–term behavior of the savings account changes as the initial deposit changes. Now we look at how the behavior of our constrained population model changes as the value of \(b\) changes. We take a strictly graphical approach.

Notice that the behavior of the system changes quite dramatically as \(b\) changes. For small values of \(b\text{,}\) the behavior is very regular. But for larger values, it is quite chaotic. This illustrates that we must be careful about using a model of this form if we are unsure of the value of \(b\text{.}\) The value of \(b\) dramatically affects the behavior of the system. If we use a wrong value of \(b\text{,}\) our analysis of the system could be very inaccurate.
